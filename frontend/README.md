# Car Helper Frontend

Vue 3 前端界面

## 安装依赖

```bash
npm install
```

## 开发运行

```bash
npm run dev
```

访问：http://localhost:3000

## 构建生产版本

```bash
npm run build
```

## 技术栈

- Vue 3
- Vite
- ECharts
- Axios

## 目录结构

```
frontend/
├── src/
│   ├── components/     # 组件
│   ├── views/          # 页面
│   ├── utils/          # 工具函数
│   ├── App.vue         # 根组件
│   ├── main.js         # 入口文件
│   └── style.css       # 全局样式
├── public/             # 静态资源
├── index.html          # HTML模板
├── vite.config.js      # Vite配置
└── package.json        # 依赖配置
```
