# 懂车帝爬虫脚本说明

本目录包含从懂车帝（dongchedi.com）爬取车型数据的历史脚本。

## 文件说明

### get_info.ipynb
- **类型**：Jupyter Notebook
- **功能**：爬取车型详细参数（完整版）
- **数据来源**：`https://www.dongchedi.com/auto/params-carIds-x-{car_id}`
- **爬取内容**：
  - 车型基本信息（车名、品牌、级别、能源类型等）
  - 详细参数（车身、发动机、变速箱、底盘、配置等30+项）
  - 输出格式：JSON（嵌套字典结构）

### crawl_dongchedi_v2.py
- **类型**：Python脚本
- **功能**：爬取车型概要信息（轻量版）
- **数据来源**：
  - 车系首页：`https://www.dongchedi.com/auto/series/{car_id}`
  - 评分页：`https://www.dongchedi.com/auto/series/score/{car_id}-x-x-x-x-x-x`
- **爬取内容**：
  - 基本信息：车名、品牌、车型、经销商报价、厂商指导价
  - 关键参数：百公里加速、能源类型、发动机、变速箱
  - 用户评分：综合评分、外观、内饰、配置、空间、舒适性、操纵、动力（8项）
  - 输出格式：Excel（car_info.xlsx）

### 工作流程
1. **获取车系ID**：从懂车帝车型库API获取所有车系ID列表
2. **数据爬取**：遍历ID列表，爬取每个车系的详细信息
3. **数据清洗**：处理缺失值、异常值
4. **数据导出**：JSON或Excel格式

## 历史版本说明

这些脚本代表了项目的早期探索阶段：
- **V1.0**（2025-09）：使用向量数据库（Chroma）+ RAG方案
- **V2.0**（2025-10）：改用Neo4j知识图谱 + LangGraph Agent（当前版本）

早期方案的局限性：
- 向量检索不够精确（语义相似但需求不匹配）
- 无法支持复杂的多条件筛选
- 数据结构不适合对比分析

当前方案的优势：
- 参数化Cypher查询（精确匹配）
- 知识图谱支持复杂关系查询
- Agent自动选择合适的工具
